# Remix requests

The collection, lyric sheet and published prompt page link to
`/distonyc/?remix=<public-song-id>`. The regular sign-in and request review remain
required. Opening a link makes no request or production writes.

The editable idea carries the source title and public idea/sound. Refinements
start with the source voice, a recognizable-hook preference, and a matching
basis recording when its title exists in the advertised basis inventory.
Available public lyrics within the request limits are included in adaptation
mode. No private notes, author identity, reference snapshots or worker settings
are copied. The listener can edit or clear these settings before confirmation.

An existing server draft or unsent idea is preserved until the visitor selects
the explicit start/use-remix button. Remix defaults belong only to the new
draft; normal new-request actions clear the remix URL. This uses the existing
request contract and needs no backend or worker deployment.
